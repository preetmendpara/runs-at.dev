## How each check was made

- **Domain and owner mapping:** claim file `domains/<claim>.json` → `owner.github` → `owners/<login>.json` lists the claim (all true).
- **Original registry data:** the `records` or `subdomains.<label>` entry of the claim file, planned by `lib/dns.js planDnsChanges` (the same planner sync-dns uses).
- **Target reachability:** CNAME and MX targets resolved through public resolvers (1.1.1.1, 8.8.8.8); A targets and resolved CNAME targets checked for TCP 443.
- **Host serves the name:** HTTPS (then HTTP) request to the target address with the claimed name as SNI and Host (`curl --resolve`), recording the HTTP status and the host's "not configured" page.
- **Publishable:** CNAME-exclusivity and rdata validation as in `scripts/export-zone.mjs`; the CI integration test (`.github/workflows/powerdns-integration.yml`) then serves every one of them from a real PowerDNS primary and secondary.
